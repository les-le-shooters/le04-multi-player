# le04-multi-player

这是一个实验性的补丁，允许**2 到 3 名玩家一起玩 le04（连缘天影战记　～ Brilliant pagoda or haze castle）**，支持本地多人和联机。多人玩法参考了
[RUEEE/th06_multi_net](https://github.com/RUEEE/th06_multi_net) 和
[sbrik1111/th07_multi_player](https://github.com/sbrik1111/th07_multi_player)。

本项目不包含游戏本体和数据（`Le04.exe`、`dat.led` 等）。请使用官方的 1.20f 版本游戏。

## 现状

故事模式和练习模式均已支持本地 2/3 人游玩及在线 2/3 人联机，并已充分测试过（包括锁步和回滚方法）。

仍处于实验阶段，可能偶有不同步情况和其他 bug。

## 已知问题

- **在极少数情况下，游戏仍可能出现不同步。** 如果游戏画面上方出现红字"已不同步"时，所有人退出并重新开始（尽管如此，程度较轻时也可以继续游戏，因为小量的不同步常常是双方难以察觉的，但会随时间推移程度增大）。

## 功能

* **支持 2～3 人联机游玩**，基于 UDP。主机是 1P，客机是 2P 和 3P；3 人时两个客机也会尝试直连
* **主机要能被连接**：需放行 UDP 端口（IPv6、端口转发或虚拟局域网）
* **支持本地 2～3 人游玩**：可使用键盘和手柄
* 每人可选择**自己的主 / 副 / 支援机**，使用**自己的升级**
* 残机、血量、Bomb、火力每人独立计算；酒共享
* 残机和火力可以在玩家之间转移；残机用完的人变成幽灵，可以被复活
* **回滚**（默认为开）：系统会对远程输入进行预测，直至实际输入数据到达；因此，输入延迟通常仅为 1–4 帧。
* 界面支持中文 / English / 日本語 / 한국어

## 游玩

1. 把 `le04multi.dll` 和 `Le04_Multi_Maker.exe` 放入游戏文件夹内（和 `Le04.exe` 同级）
2. 双击 `Le04_Multi_Maker.exe`，生成 `Le04_Multi.exe`。此操作仅需执行一次，且不会修改原有的 `Le04.exe` 文件。
3. 运行 `Le04_Multi.exe`，程序会首先弹出设置窗口
4. 选择模式：单人 / 本地双人 / 本地三人 / 联机：主机 / 联机：客机。若作为客机，在「主机地址」里输入主机的地址
5. 点击「开始」，之后和原版一样在菜单里选模式、难度和自机
6. 联机时，由主机负责选择模式、难度及关卡（或练习）并开始游戏；客机在连接成功后，各自选择机体即可开始游戏。当所有玩家都准备就绪后，游戏正式开始。

本地游玩时，请在设置窗口中选择 2P 和 3P 的机体（默认与 1P 相同）。若要游玩原版游戏，请照常运行 `Le04.exe`。

客机的连接状态显示在菜单左下角。

客机玩家可以自由选择模式和关卡，但游戏开始后，这些选择将以主机玩家的设定为准。在等待游戏开始期间，可按下 `Esc` 取消联机，转为单人游玩。

主机要在 Windows 防火墙里允许 `Le04_Multi.exe`（UDP，默认端口 17723）通过。若通过互联网联机时推荐用 IPv6 直连：设置窗口里的「本机 IPv6」即为主机的地址，此外，可能还需要在路由器的 IPv6 防火墙中放行相应端口。若没有 IPv6，主机玩家需要在路由器上进行端口转发，或使用虚拟局域网软件(Radmin等）。

## 操作

联机时每人都使用自己的键盘或手柄，按原版的键位。

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 |
| 射击 | `Z` |
| Bomb | `X` |
| 低速 | `Shift` |
| 对话 | `Z` 翻页，按住 `X` 快进 |
| 暂停 | `Esc` |

本地多人共用一个键盘，因此 2P 用另一组键。3P 没有键盘键位，需要使用手柄。

| 操作 | 2P 的按键 |
| --- | --- |
| 移动 | `W` / `A` / `S` / `D` |
| 射击 | `J` |
| Bomb | `K` |
| 低速 | `L` |

本地游玩时，1P、2P、3P 也可以分别用 1、2、3 号手柄。

## 设置

人数、回滚和游戏规则都由主机决定，客机在加入时会自动应用这些设置。语言和延迟设置则由各机独立生效；延迟填 0 时按网络情况自动调整（推荐）。

规则默认都为勾选状态：

- 「自机狙瞄准离敌人最近的机体」：不勾选此项时，敌人的自机狙只瞄准 1P
- 「所有自机都能决定路径方向」：不勾选此项时，只有 1P 能改变路线
- 「部分符牌自机相关攻击对全员发动」：不勾选此项时，部分符卡的特定攻击只对一个自机发动（见下面的「部分符卡」）

开局时，模式、难度、关卡或练习的选择、随机种子和设置里的即死模式以主机为准。自机（主 / 副 / 支援）、升级和 Config 里的Flashbomb=Bomb则由每位玩家自行决定。。

## 多人时的变化

- **Boss 受到的伤害**：两人在场时 ×0.75，三人在场时 ×2/3
- **敌人的自机狙**默认瞄准离那个敌人或 Boss 最近的非幽灵自机
- **道具**飞向离它最近的非幽灵自机。任何越过自动收集线的人都会触发自动回收，回收线的高度随每个玩家的升级而变化
- **路线**默认把所有人的偏移量相加减：在同一边时相加，在两侧时会相减
- **残机转移**：两个自机靠近到 24 像素以内，松开射击、按住低速 90 帧，给对方 1 个残机；对方残机已用完时直接复活
- **火力转移**：两个自机靠近到 24 像素以内，连点 5 次射击，给对方 1.00 火力（自己至少要留 1.00）
- **游戏结束**：所有人都耗尽残机才会结束游戏。续关时所有人一起复活
- **符卡收取**：任何人被弹就不会取得符卡
- **作用在整个关卡上的升级**取在场的人（不计幽灵）里效果最强的一个
- **部分符卡**（可选规则，默认开）的部分攻击对每个自机都发动，其他难度的同一张卡也适用：
  - 無知「ヒトが恐るるは暴るる己」
  - 霊獣「青蛙神の欲」
  - 怨炎「断魂烈刃」
  - 「二つの煌き」
  - 平穏｢東西廻廊の雀｣
  - 再現と体験「リプレイ」
  - 「運命のルーレット」
  - 「背中に突き立てる思い」
- **HUD**：每台电脑上，游戏自己的 HUD 显示本机玩家的数据（本地多人时是 1P）。其他人的 LV、残机、HP、屏障、火力、瞬雷槽和 Bomb 显示在左下角的面板里
- **掉线**：某个客机掉线时，主机会让其退出（显示"xP 已退出"），其他人继续游戏。和主机断开的客机可继续单人游戏
- **Replay**：多人局不生成Replay

## 回滚

回滚模式下，在实际输入到达之前，系统会利用近期收到的远程输入进行预测性回滚。如果预测结果与实际输入不符，游戏会回退至受影响的帧，并重新执行模拟过程。若预测跨度超过 15 帧，或者处于无法撤销的状态（如暂停、菜单界面、加载过程、场景切换等），游戏则会进入等待状态，直到获取到所有参与方的输入。

## 编译

需要 Windows 和 Visual Studio 2022 Build Tools（MSVC，x86）。

```
build.bat
```

- 生成 `build\le04multi.dll` 和 `build\Le04_Multi_Maker.exe`
- 也可以用 Python（需要 `pefile`）代替 Maker：`python tools/patch_exe.py <你的 Le04.exe> <输出的 Le04_Multi.exe>`

## 限制

- 处于实验阶段。不支持 NAT 穿透或中继，也未提供加密或身份验证机制。
- 仅限与您信任的人共同游玩，不适用于搭建公共服务器。
- 所有人必须使用**同一版的 `Le04_Multi.exe`、`le04multi.dll` 和同样的游戏数据**。
- 若延迟或丢包超出了预测窗口的容许范围，游戏会停下等待缺少的按键
- 多人模式下不支持生成Replay

## 数据与权利

- 请不要再配布任何游戏文件（`Le04.exe`、`dat.led` 等）。这些文件虽为运行游戏所必需，但每位玩家应使用各自持有的游戏的文件。
- `Le04_Multi.exe` 是基于你个人的 `Le04.exe` 生成的，其中包含了游戏程序。请勿再配布此文件；若他人需要，可自行使用 `Le04_Multi_Maker.exe` 生成
- 连缘天影战记　～ Brilliant Pagoda or Haze Castle的权利属于原作者。
