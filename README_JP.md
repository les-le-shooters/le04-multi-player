# le04-multi-player

**le04（連縁天影戦記　～ Brilliant pagoda or haze castle）を 2～3 人で一緒に遊べるようにする**実験的な改造です。1 台の PC でも、オンラインでも遊べます。マルチプレイの仕組みは
[RUEEE/th06_multi_net](https://github.com/RUEEE/th06_multi_net) と
[sbrik1111/th07_multi_player](https://github.com/sbrik1111/th07_multi_player) を参考にしています。

ゲーム本体とデータ（`Le04.exe`、`dat.led` など）は含まれていません。各自の正規の 1.20f を使ってください。

## 現状

ローカル 2 / 3 人、オンライン 2 / 3 人（ロックステップとロールバックの両方式）で、ストーリーモードとプラクティスを確認しています。

まだ実験版なので、同期ずれやその他の不具合が残っている可能性があります。

## 既知の問題

- **まれに同期がずれることがあります。** 画面上部に赤字で「同期がずれました」と出たら、全員抜けてからマッチングし直してください。

## できること

* **2～3 人のオンライン**（UDP）。ホストが 1P、ゲストが 2P と 3P。3 人のときはゲスト同士も直接つなごうとします
* **ホストは外からつながる必要があります**：UDP ポートを開けてください（IPv6、ポート開放、仮想 LAN）
* **ローカル 2～3 人**：キーボードとパッド
* 各自が**自分のメイン / サブ / サポート自機**を選び、**自分のアップグレード**を使います
* 残機、HP、ボム、パワー、得点は各自。お酒は共通
* 残機とパワーをプレイヤー間で受け渡せます。残機がなくなるとゴーストになり、復活させられます
* **ロールバック**（標準でオン）：相手の入力が届くまでは予測で進めるので、入力遅延はたいてい 1～4 フレームです
* UI は English / 日本語 / 中文 / 한국어

## 遊び方

1. `le04multi.dll` と `Le04_Multi_Maker.exe` をゲームフォルダ（`Le04.exe` と同じ場所）に入れます
2. `Le04_Multi_Maker.exe` をダブルクリックすると `Le04_Multi.exe` が作られます。これは 1 回だけで、`Le04.exe` は変更されません
3. `Le04_Multi.exe` を起動すると、先に設定ウィンドウが開きます
4. モードを選びます：シングル / ローカル 2 人 / ローカル 3 人 / オンライン：ホスト / オンライン：ゲスト。ゲストは「ホスト」にホストのアドレスを入れます
5. 「開始」を押します。あとは原作どおりメニューでモード、難易度、自機を選びます
6. オンラインでは、ホストがモード、難易度、ステージ（またはプラクティスの選択）を選んでゲームを始めます。ゲストはつながったら自分の自機を選んでゲームを始めます。全員が始めると同時にゲームが始まります

ローカルでは、設定ウィンドウで 2P・3P の自機を選びます（標準は 1P と同じ）。原作を遊ぶときは、いつもどおり `Le04.exe` を起動してください。

ゲストの接続状態はメニューの左下に出ます。

ゲストのモードやステージは何でもかまいません。開始時にホストの選択に置き換わります。開始を待っている間は `Esc` でキャンセルし、1 人で始められます。

ホストは Windows ファイアウォールで `Le04_Multi.exe` を許可してください（UDP、標準ポート 17723）。インターネット越しには IPv6 での直接接続がおすすめです。設定ウィンドウの「この PC の IPv6」がホストのアドレスで、ルーターの IPv6 ファイアウォールでもポートを開ける必要があるかもしれません。IPv6 がない場合、ホストはルーターでのポート開放か仮想 LAN が必要です（仮想 LAN が中継すると遅延がかなり大きくなります）。

## 操作

オンラインでは、ゲストも含めて各 PC が自分のキーボードかパッドを原作のキー配置で使います。

| 操作 | キー |
| --- | --- |
| 移動 | 方向キー |
| ショット | `Z` |
| ボム | `X` |
| 低速 | `Shift` |
| 会話 | `Z` で送る、`X` 長押しで早送り |
| ポーズ | `Esc` |

ローカルでは 1 つのキーボードを共有するので、2P は別のキーを使います。3P にはキーボードの割り当てがなく、パッドが必要です。

| 操作 | 2P のキー |
| --- | --- |
| 移動 | `W` / `A` / `S` / `D` |
| ショット | `J` |
| ボム | `K` |
| 低速 | `L` |

ローカルでは 1P・2P・3P がそれぞれ 1・2・3 番のパッドも使えます。

## 設定ウィンドウ

人数、「ロールバック」、ゲームのルールはホストが決め、ゲストには接続時にこれらの設定が届きます。言語と遅延は各 PC のものです。遅延 0 で回線に合わせて自動調整します（推奨）。

ルールは標準ですべてオンです：

- 「自機狙いは一番近い機体を狙う」：チェックなしでは、敵の自機狙いは 1P だけを狙います
- 「全員で進路の方向を決める」：チェックなしでは、1P だけが進路ゲージを動かせます
- 「一部スペルの自機対象の攻撃を全員に」：チェックなしでは、一部のスペルは 1 機だけに向かいます（下の「一部のスペル」を参照）

ゲーム開始時、モード、難易度、ステージまたはプラクティスの選択、乱数の種、Config の即死モードはホストのものになります。自機（メイン / サブ / サポート）、アップグレード、Config のフラッシュボム＝ボムは各自のものです。

## マルチプレイでの変更点

- **ボスへのダメージ**は 2 人のとき ×0.75、3 人のとき ×2/3
- **敵の自機狙い**は、標準ではその敵やボスに一番近い、場に残っている自機を狙います
- **アイテム**は一番近い、場に残っている自機に飛んでいきます。自動回収ラインは誰が越えても発動し、ラインの高さは各自のアップグレードで決まります
- **進路ゲージ**は標準で全員のずれを合計します。同じ側にいると速く進み、左右に分かれると打ち消し合います
- **残機の受け渡し**：2 機を 24 ピクセル以内に重ね、ショットを離して低速を 90 フレーム押し続けると、相手に残機を 1 つ渡します。残機がなくなった相手はその場で復活します
- **パワーの受け渡し**：2 機を 24 ピクセル以内に重ね、ショットを 5 回押すと、相手にパワー 1.00 を渡します（自分は最低 1.00 残します）
- **ゲームオーバー**は全員がいなくなったときだけです。コンティニューすると全員復活します
- **スペルカードボーナス**は誰かが被弾すると失敗します
- **ステージ全体にかかるアップグレード**は、場に残っているプレイヤー（ゴーストは除く）の中で一番効果の高いものを使います
- **一部のスペル**（ルール、標準でオン）はすべての自機に向けて発動します。他の難易度の同じスペルも同様です：
  - 無知「ヒトが恐るるは暴るる己」
  - 霊獣「青蛙神の欲」
  - 怨炎「断魂烈刃」
  - 「二つの煌き」
  - 平穏｢東西廻廊の雀｣
  - 再現と体験「リプレイ」
  - 「運命のルーレット」
  - 「背中に突き立てる思い」
- **HUD**：各 PC で、ゲーム本来の HUD はその PC のプレイヤーを表示します（ローカルでは 1P）。他の人の LV、残機、HP、バリア、パワー、フラッシュボムゲージ、Bomb は左下のパネルに出ます
- **切断**：ゲストが切断すると、ホストはそのゲストを退出させ（「xP 退出」）、残りの人は続けます。ホストとの接続が切れたゲストは 1 人で続けます
- **リプレイ**：マルチプレイでは記録しません

## ロールバック

ロールバックでは、実際の入力が届くまで、相手の直近の入力のまま進めます。予測が違っていたら、そのフレームに戻ってシミュレーションをやり直します。予測が 15 フレームを超えそうなときや、取り消せない場面（ポーズ、メニュー、ロード、場面の切り替え）では、全員の入力がそろうのを待ちます。

## ビルド

Windows と Visual Studio 2022 Build Tools（MSVC、x86）が必要です。

```
build.bat
```

- `build\le04multi.dll` と `build\Le04_Multi_Maker.exe` ができます
- Maker の代わりに Python（`pefile` が必要）も使えます：`python tools/patch_exe.py <自分の Le04.exe> <出力する Le04_Multi.exe>`

## 制限

- 実験版です。NAT 越えや中継はなく、暗号化や認証もありません
- 信頼できる人と遊ぶためのもので、公開サーバー向けではありません
- 全員が**同じ `Le04_Multi.exe`、`le04multi.dll`、同じゲームデータ**を使う必要があります
- 遅延やパケットロスが予測の範囲を超えると、足りない入力を待つ間ゲームが止まります
- マルチプレイではリプレイを記録しません

## データと権利

- ゲームのファイル（`Le04.exe`、`dat.led` など）は再配布しないでください。実行に必要ですが、各自が自分のゲームから用意してください。
- `Le04_Multi.exe` は自分の `Le04.exe` から作られ、ゲーム本体のプログラムを含みます。再配布しないでください。必要な人は `Le04_Multi_Maker.exe` で各自作ってください
- 連縁天影戦記　～ Brilliant Pagoda or Haze Castle の権利は原作者に帰属します。
